# Неделя 06. Vite и модульность

## Задание

Нужно создать проект на Vite с шаблоном `vanilla-ts`, организовать код по ES-модулям и настроить алиас импорта. В папке `src/` создай структуру `src/utils/formatters.ts` и `src/components/greeter.ts`.

В `formatters.ts` создай и экспортируй функцию `formatDate(date: Date): string`. В `greeter.ts` создай и экспортируй функцию `sayHello(name: string): string`, импортируй в нее `formatDate` и используй дату при формировании приветственной строки. В `main.ts` импортируй `sayHello` и вызови функцию.

В `vite.config.ts` настрой алиас `@/`, чтобы импорт мог выглядеть как `import { formatDate } from '@/utils/formatters';`. После этого проверь, что проект успешно собирается через `npm run build` и запускается через `npm run dev`.

## Что сдать

Нужен проект с модульной структурой, короткими путями импорта и работающими функциями. Преподавателю отправляется ссылка на репозиторий с выполненным заданием.
