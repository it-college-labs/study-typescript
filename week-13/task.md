# Неделя 13. Финальный проект, часть 2

## Задание

Нужно реализовать ядро финального проекта: два или три ключевых модуля с бизнес-логикой. Модули должны быть созданы в отдельных файлах проекта, например в папке `src/core/`, и должны импортировать типы, которые были спроектированы на прошлой неделе в `src/types.ts`.

В коде модулей обязательно должно быть как минимум два разных примера использования Utility Types: `Partial`, `Required`, `Pick`, `Omit` или `ReturnType`. Например, функция обновления может принимать `Partial<YourType>`, а функция для вывода списка может возвращать `Pick<YourType, 'field1' | 'field2'>`.

Реализуй две или три ключевые операции для своей предметной области, например добавление элемента, поиск элемента, обновление элемента, удаление элемента или получение статистики. Экспортируй только публичное API модуля и проверь, что код компилируется без ошибок командой `tsc --noEmit`.

## Что сдать

Нужно предоставить ссылку на репозиторий проекта. В описании Pull Request или Merge Request к 14-й неделе нужно кратко указать, в каких функциях и как были применены Utility Types.
