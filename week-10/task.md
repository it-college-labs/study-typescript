# Неделя 10. CLI для todo-приложения

## Задание

Это продолжение задания недели 9. Нужно дописать команды для консольного todo-приложения на базе `TaskManager`: список задач, добавление задачи, завершение задачи и удаление задачи. В исходных файлах уже есть общий сервис CLI, интерфейс команды и готовая команда помощи; файлы с командами `list`, `add`, `done` и `rm` нужно реализовать самостоятельно.

Команда помощи должна показывать список команд: `ls` или `list` с флагом `-a` для вывода доступных или всех задач, `add [long title]` для добавления новой задачи, `done [task-id]` для завершения задачи и `rm [task-id]` для удаления задачи. Работа приложения должна соответствовать примеру из `shell_output.txt`.

Сервис CLI должен перед выполнением команды загрузить `todo.json`, выполнить подходящую команду и сохранить `todo.json`, если команда изменила список задач. Команда помощи не должна менять список и поэтому не должна запускать сохранение. Модели `Task` и `TaskManager` берутся из задания недели 9, поэтому эту неделю нужно выполнять как продолжение предыдущей папки проекта.

## Что сдать

Нужно получить работающее консольное приложение `todo`, которое умеет выводить помощь, добавлять задачи, показывать активные и все задачи, закрывать задачу и удалять задачу. В качестве ориентира используй `src/index.ts`, `src/services/cli.ts`, `src/services/types.ts`, `src/services/commands/help.ts` и пример терминального вывода.
