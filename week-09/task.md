# Неделя 09. Исходные файлы для todo-модели

## Задание

Нужно создать проект в Vite с шаблоном `vanilla` и TypeScript, заменить или создать `vite.config.js` из этой папки, а затем дописать код в `src/models/Task.ts` и `src/models/TaskManager.ts`. Заготовки интерфейсов, классов и конфигурации перенесены из gist.

Модель `Task` должна описывать задачу с `id`, `title`, `complete` и `createdAt`, уметь закрывать задачу и сообщать, завершена ли она. `TaskManager` должен хранить задачи, загружать их из JSON, сохранять в JSON, добавлять задачу, искать задачу по id, закрывать задачу и возвращать список незавершенных задач.

Файл `todo.json` показывает пример результата сохранения. Важно помнить, что при сохранении в JSON даты превращаются в строки, поэтому после чтения с диска `createdAt` нужно преобразовывать обратно к типу `Date`.

## Пример использования

Для сохранения можно создать `TaskManager`, добавить задачи, закрыть одну из них, вывести `availableTasks()` и вызвать `save("todo.json")`. Для чтения можно создать новый `TaskManager`, вызвать `await tm.load("todo.json")` и вывести `availableTasks()`.
