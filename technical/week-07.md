### **📚 Конспект для студентов: Асинхронность в TypeScript**

**Цель:** Научиться писать безопасный и предсказуемый асинхронный код в TypeScript, работая с внешними API.

#### **1. Введение: Зачем типизировать асинхронность?**
В JavaScript асинхронные операции (запросы к серверу, чтение файлов) традиционно работают с `Promise`. TypeScript добавляет к этому **статическую типизацию**. Это значит, что ещё до запуска кода вы можете точно указать:
*   **Какого типа данные вернёт асинхронная функция?** (например, `Promise<User>`).
*   **С какими данными вы будете работать после их получения?** (например, объект со свойствами `id`, `name`).

Это резко снижает количество ошибок, связанных с опечатками в именах полей или неверными предположениями о структуре данных.

#### **2. Типизация Promise**
Тип `Promise` в TypeScript является **обобщённым (generic)**. Это означает, что он работает с другим типом, который указывается в угловых скобках `<T>`.

*   **`Promise<T>`** — промис, который будет выполнен (**resolved**) со значением типа `T`.
*   Если промис будет отклонён (**rejected**), значением ошибки будет `any` или `unknown` (в зависимости от настройки `strict`).

**Примеры:**
```typescript
// Промис, который выполнится строкой
const promiseString: Promise<string> = new Promise((resolve) => {
  setTimeout(() => resolve("Готово!"), 1000);
});

// Функция, возвращающая промис с числом
function fetchNumber(): Promise<number> {
  return new Promise((resolve) => resolve(42));
}

// Промис, который выполнится массивом пользователей (по интерфейсу User)
const usersPromise: Promise<User[]> = fetch('/api/users').then(r => r.json());
```

#### **3. Async/Await — синхронный стиль для асинхронного кода**
Ключевые слова `async` и `await` делают код линейным и удобочитаемым. TypeScript отлично с ними работает.

*   **`async`**: Любая функция, объявленная с этим словом, автоматически возвращает `Promise`. Если функция возвращает значение `T`, её реальный возвращаемый тип будет `Promise<T>`.
    ```typescript
    async function getGreeting(): Promise<string> {
      return "Привет, мир!"; // Тип возвращаемого значения автоматически Promise<string>
    }
    ```

*   **`await`**: Это ключевое слово можно использовать **только внутри `async`-функций**. Оно "приостанавливает" выполнение функции до тех пор, пока переданный ему `Promise` не будет выполнен, и возвращает значение типа `T`.
    ```typescript
    async function example() {
      const greeting: string = await getGreeting(); // "Разворачиваем" Promise<string> в string
      console.log(greeting); // Вывод: "Привет, мир!"
    }
    ```
    **Важно:** Без `await` вы получите объект `Promise`, а не сами данные.

#### **4. Практика: Запрос к реальному API с полной типизацией**
Давайте напишем функцию для получения данных о пользователе с публичного сервиса **JSONPlaceholder**.

**Шаг 1: Определим тип (интерфейс) данных.**
Сначала нужно описать, какую структуру данных мы ожидаем от сервера. Изучим ответ API.
```typescript
// Интерфейс, описывающий модель пользователя с JSONPlaceholder
interface User {
  id: number;
  name: string;
  username: string;
  email: string;
  address: {
    // ... можно описать и вложенные объекты
  };
  phone: string;
  website: string;
  company: {
    // ...
  };
}
```

**Шаг 2: Напишем типизированную асинхронную функцию.**
```typescript
async function fetchUser(userId: number): Promise<User | null> {
  // 1. Функция объявлена как `async`, значит, она возвращает Promise.
  // 2. Возвращаемый тип Promise<User | null> означает:
  //    - В случае успеха вернётся User.
  //    - В случае ошибки (или если пользователь не найден) мы можем вернуть null.

  try {
    // Выполняем запрос. `fetch` возвращает Promise<Response>.
    const response: Response = await fetch(`https://jsonplaceholder.typicode.com/users/${userId}`);

    // Проверяем, успешен ли HTTP-ответ (статус 200-299).
    if (!response.ok) {
      // Если ответ не успешен (например, 404), выбрасываем ошибку.
      throw new Error(`Ошибка HTTP: ${response.status}`);
    }

    // Парсим тело ответа как JSON.
    // Тип `User` для переменной `userData` подсказывает TypeScript структуру объекта.
    const userData: User = await response.json();

    // Возвращаем данные. Так как функция `async`, это равносильно return Promise.resolve(userData).
    return userData;

  } catch (error) {
    // Перехватываем любые ошибки: сетевые, ошибки парсинга JSON, выброшенные нами.
    console.error('Не удалось загрузить пользователя:', error);
    // Возвращаем null в качестве индикатора ошибки.
    return null;
  }
}
```

**Шаг 3: Используем функцию.**
```typescript
async function displayUser() {
  const user = await fetchUser(1); // user имеет тип User | null
  if (user) {
    // TypeScript точно знает, что здесь user имеет тип User (не null).
    console.log(`Имя пользователя: ${user.name}`); // Автодополнение сработает для user.
  } else {
    console.log('Пользователь не найден.');
  }
}
```

#### **5. Полезный тип: Awaited**
TypeScript 4.5+ предоставляет утилитарный тип `Awaited`. Он рекурсивно "разворачивает" промисы.
```typescript
// Пример: допустим, у нас есть функция, возвращающая Promise<Promise<User>>
type NestedPromise = Promise<Promise<User>>;
type ResolvedType = Awaited<NestedPromise>; // ResolvedType будет равен просто User

// Это полезно в сложных обобщённых функциях или типах.
```
