### **📚 Vite и модульность**

**Цель:** Научиться использовать современный инструмент сборки Vite и организовывать код с помощью ES-модулей.

#### **1. Что такое Vite и зачем он нужен?**
Vite (фр. «быстрый») — это современный инструмент для сборки и разработки фронтенд-проектов.
*   **Проблема:** Традиционные сборщики (Webpack) «собирают» весь проект перед запуском, что медленно.
*   **Решение Vite:** Использует нативные ES-модули браузера для разработки. Сервер запускается мгновенно, а HMR (Hot Module Replacement) обновляет код без перезагрузки страницы.

#### **2. Создание и структура проекта на Vite**
1.  **Создание проекта:**
    ```bash
    npm create vite@latest название-проекта -- --template vanilla-ts
    ```
    *   `vanilla-ts` — шаблон для чистого TypeScript. Для React используйте `react-ts`.
2.  **Переходим в папку и устанавливаем зависимости:**
    ```bash
    cd название-проекта
    npm install
    ```
3.  **Запуск dev-сервера:**
    ```bash
    npm run dev
    ```
4.  **Структура проекта:**
    ```
    ваш-проект/
    ├── src/           # Исходный код
    ├── index.html     # Главный HTML-файл (точка входа)
    ├── vite.config.ts # Конфигурация Vite
    ├── package.json
    └── ...
    ```

#### **3. Модульность в ES6: экспорт и импорт**
Модульность позволяет разбивать код на логические части (файлы) и управлять зависимостями.
*   **Создание модуля (файл `math.ts`):**
    ```typescript
    // Именованный экспорт (может быть несколько)
    export function sum(a: number, b: number): number {
        return a + b;
    }
    export const PI = 3.14;

    // Экспорт по умолчанию (один на модуль)
    export default class Calculator { /* ... */ }
    ```
*   **Импорт модуля (файл `main.ts`):**
    ```typescript
    // Импорт именованных экспортов
    import { sum, PI } from './math.js';

    // Импорт с переименованием (если есть конфликт имен)
    import { sum as add } from './math.js';

    // Импорт всего содержимого модуля в один объект
    import * as MathUtils from './math.js';
    console.log(MathUtils.sum(2, 2));

    // Импорт экспорта по умолчанию
    import Calculator from './math.js';
    ```

#### **4. Настройка алиасов (коротких путей) в Vite**
Чтобы избежать длинных и запутанных относительных путей (`import { something } from '../../../utils';`), используют алиасы.
1.  **Установите `@types/node`** (для работы с `path` в TypeScript):
    ```bash
    npm install -D @types/node
    ```
2.  **Настройте алиас в `vite.config.ts`:**
    ```typescript
    import { defineConfig } from 'vite';
    import path from 'path';

    export default defineConfig({
      resolve: {
        alias: {
          '@': path.resolve(__dirname, 'src'), // '@' будет указывать на папку src/
        },
      },
    });
    ```
3.  **Используйте алиас в импортах:**
    ```typescript
    // Вместо этого:
    import { helper } from '../../utils/helpers';

    // Используйте это:
    import { helper } from '@/utils/helpers';
    ```

6.  **Настройте алиас `@/`** в `vite.config.ts`, чтобы использовать импорт вида `import { formatDate } from '@/utils/formatters';`.
7.  Убедитесь, что проект успешно собирается (`npm run build`) и работает (`npm run dev`).
