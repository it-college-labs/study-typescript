### **📚 **Конспект для студентов: TypeScript – Классы и ООП**

**Цель:** Научиться использовать классы для создания объектов по единому шаблону, управлять доступом к их внутренним данным и строить иерархии с помощью наследования.

#### **1. Введение: что такое ООП?**
**Объектно-ориентированное программирование (ООП)** — это подход, при котором программа строится из **объектов**, взаимодействующих друг с другом. Каждый объект — это экземпляр **класса**.
*   **Класс** — это чертёж, описание, шаблон. Он определяет, какие **данные (свойства)** и **действия (методы)** будут у объекта.
*   **Объект** — это конкретная сущность, созданная по этому чертежу.

**Аналогия:** Класс `РецептБорща` (ингредиенты, шаги). Объекты — `БорщМамы`, `БорщБабули`, созданные по этому рецепту, но со своими особенностями.

#### **2. Создание простого класса**
Объявим класс для представления товара в интернет-магазине.

```typescript
class Product {
    // 1. Свойства (поля) класса
    title: string;
    price: number;

    // 2. Конструктор - специальный метод для инициализации нового объекта
    constructor(productTitle: string, productPrice: number) {
        this.title = productTitle;
        this.price = productPrice;
    }

    // 3. Метод класса - действие, которое может выполнить объект
    getDescription(): string {
        return `Товар "${this.title}" стоит ${this.price} руб.`;
    }
}

// 4. Создание объекта (экземпляра класса) с помощью оператора 'new'
const myBook = new Product("Книга по TypeScript", 1500);
console.log(myBook.getDescription()); // Товар "Книга по TypeScript" стоит 1500 руб.
```
**Ключевые элементы:**
*   `constructor(...)` — вызывается автоматически при `new Product(...)`.
*   `this` — ссылка на **текущий экземпляр** объекта.
*   `new` — оператор для создания нового объекта по чертежу-классу.

#### **3. Модификаторы доступа и инкапсуляция**
**Инкапсуляция** — это принцип ООП, который позволяет скрывать внутреннее состояние объекта и предоставлять доступ к нему только через строго определённые методы.

В TypeScript это реализуется с помощью **модификаторов доступа**:

| Модификатор | Описание | Пример |
| :--- | :--- | :--- |
| **`public`** | Свойство или метод доступны отовсюду. Это значение **по умолчанию**. | `public id: number;` |
| **`private`** | Свойство или метод доступны **только внутри самого класса**. Это основа инкапсуляции. | `private secretKey: string;` |
| **`protected`** | Доступны внутри класса и внутри всех классов-**наследников**. | `protected internalId: number;` |
| **`readonly`** | Свойство может быть установлено только при объявлении или в конструкторе. После этого его нельзя изменить. | `readonly createdAt: Date;` |

**Пример с `private`:**
```typescript
class BankAccount {
    private balance: number; // Скрытое внутреннее состояние

    constructor(initialBalance: number) {
        this.balance = initialBalance;
    }

    // Публичный метод — безопасный интерфейс для работы со счёттом
    public deposit(amount: number): void {
        if (amount > 0) {
            this.balance += amount;
            console.log(`Внесено: ${amount}. Новый баланс: ${this.balance}`);
        }
    }

    // Прямой доступ к `balance` снаружи класса НЕВОЗМОЖЕН
    // account.balance = 1000000; // ОШИБКА: Свойство 'balance' является приватным.
}
```

#### **4. Наследование (`extends`)**
**Наследование** позволяет создавать новый класс на основе существующего, перенимая его свойства и методы. Это реализует принцип **«является»** (Car **is a** Vehicle).

*   **Родительский (базовый) класс** — содержит общую логику.
*   **Дочерний (производный) класс** — наследует от родителя и добавляет специфику.

```typescript
// 1. Базовый (родительский) класс
class Vehicle {
    constructor(public brand: string, protected year: number) {}

    public startEngine(): void {
        console.log(`Двигатель ${this.brand} запущен.`);
    }
}

// 2. Дочерний класс. Ключевое слово 'extends'
class Car extends Vehicle {
    // 3. Дополнительное свойство, specific для Car
    private model: string;

    constructor(brand: string, year: number, model: string) {
        // 4. Вызов конструктора родительского класса ОБЯЗАТЕЛЕН через super()
        super(brand, year);
        this.model = model;
    }

    // 5. Расширение функциональности родителя
    public getInfo(): string {
        // Можно обратиться к protected-свойству родителя
        return `Автомобиль ${this.brand} ${this.model}, ${this.year} года выпуска.`;
    }

    // 6. Переопределение метода родителя (можно использовать `override`)
    public startEngine(): void {
        console.log(`Автомобиль ${this.model} заводится с кнопки.`);
        // Можно также вызвать оригинальный метод родителя
        super.startEngine();
    }
}

const myCar = new Car('Toyota', 2022, 'Camry');
console.log(myCar.getInfo()); // Автомобиль Toyota Camry, 2022 года выпуска.
myCar.startEngine(); // Автомобиль Camry заводится с кнопки. \n Двигатель Toyota запущен.
```

#### **5. Абстрактные классы (`abstract`)**
**Абстрактный класс** — это класс, который служит только как шаблон для других классов. Нельзя создать экземпляр абстрактного класса напрямую. Он может содержать **абстрактные методы** — методы без реализации, которые **обязаны** быть реализованы в дочернем классе.

```typescript
// Абстрактный класс
abstract class Shape {
    constructor(public color: string) {}

    // Абстрактный метод (нет тела {})
    abstract calculateArea(): number;

    // Обычный метод
    public displayInfo(): void {
        console.log(`Эта фигура цвета ${this.color}.`);
    }
}

// Конкретный класс
class Circle extends Shape {
    constructor(color: string, public radius: number) {
        super(color);
    }

    // ОБЯЗАТЕЛЬНАЯ реализация абстрактного метода
    calculateArea(): number {
        return Math.PI * this.radius ** 2;
    }
}

// const shape = new Shape("red"); // ОШИБКА! Нельзя создать экземпляр абстрактного класса.
const myCircle = new Circle("синий", 5);
console.log(myCircle.calculateArea()); // 78.5398...
myCircle.displayInfo(); // Эта фигура цвета синий.
```

#### **6. Контрольное задание К5.1**

**Задача:** Создать систему для учета транспортных средств в гараже, используя абстрактные классы, наследование и композицию.

1.  **Создайте абстрактный базовый класс `Vehicle`**.
    *   Он должен иметь свойства `brand` (марка, `string`), `year` (год выпуска, `number`, `protected`) и `id` (уникальный идентификатор, `readonly` и `private`). Для генерации `id` можно использовать `Date.now()`.
    *   Объявите **абстрактный метод** `getInfo(): string`, который будет возвращать строку с информацией о транспорте.
    *   Добавьте **публичный метод** `startEngine(): void`, который выводит в консоль `"Двигатель запущен"`.

2.  **Реализуйте два конкретных класса-наследника** от `Vehicle`.
    *   **Класс `Car`**:
        *   Добавляет свойство `model` (модель, `string`).
        *   Реализует метод `getInfo()`, возвращающий строку: `"Автомобиль [brand] [model], [year] г.в. (ID: [id])"`.
        *   **Переопределяет** метод `startEngine()`, чтобы он выводил `"Автомобиль заводится с ключа"` перед вызовом `super.startEngine()`.
    *   **Класс `Motorcycle`**:
        *   Добавляет свойство `type` (тип, например, `'cruiser'` или `'sport'`, `string`).
        *   Реализует метод `getInfo()`, возвращающий строку: `"Мотоцикл [brand], тип [type], [year] г.в. (ID: [id])"`.

3.  **Создайте класс `Garage`** для управления коллекцией.
    *   Приватное свойство `vehicles: Vehicle[]` (массив для хранения объектов).
    *   Метод `addVehicle(vehicle: Vehicle): void` для добавления транспорта в гараж.
    *   Метод `listVehicles(): void`, который перебирает массив `vehicles` и для каждого элемента выводит в консоль результат вызова `getInfo()`.
    *   Метод `findVehicleById(id: number): Vehicle | undefined` для поиска транспорта по ID.

4.  **Проверка работы:**
    *   В файле `main.ts` создайте экземпляр гаража.
    *   Создайте несколько экземпляров `Car` и `Motorcycle`.
    *   Добавьте их в гараж с помощью `addVehicle`.
    *   Вызовите `listVehicles()`, чтобы увидеть список.
    *   Попробуйте найти транспорт по ID и запустить его двигатель.

**Что проверит преподаватель:**
*   Умение работать с абстрактными классами и методами.
*   Правильное использование модификаторов доступа (`private`, `protected`, `readonly`).
*   Глубокое понимание наследования: вызов `super`, переопределение методов.
*   Применение ООП для моделирования реальной задачи (композиция в классе `Garage`).
*   Корректную работу с типами (массив `Vehicle[]` может хранить любых наследников).
