### **📚 Конспект для студентов (12-я неделя)**

**Тема:** Начало работы над финальным проектом. Архитектура и настройка.

#### **1. Цель финального проекта**
За оставшиеся недели вы создадите **законченное приложение на TypeScript**. Это может быть консольная утилита или простое веб-приложение. Главное — продемонстрировать умение применять систему типов для структурирования кода и решения практической задачи.

#### **2. Выбор темы: от идеи к сущностям**
Ваш проект должен управлять набором данных. Выберите тему, которую сможете завершить.
*   **Примеры:** Менеджер задач, Каталог книг/фильмов/игр, Трекер расходов, Список контактов, Конвертер единиц измерения.
*   **Совет:** Начните с вопроса "Какая главная *сущность* будет в моём приложении?" (Задача, Книга, Транзакция, Контакт).
*   **Определите действия:** Что можно делать с этой сущностью? (Добавить, удалить, найти, отметить как выполненное, отфильтровать).

#### **3. Шаг 1: Проектирование типов данных**
Прежде чем писать код, опишите данные. Создайте в проекте файл **`src/types.ts`**.
1.  **Определите главный интерфейс** (вашу сущность). Например, для "Менеджера задач":
    ```typescript
    // src/types.ts
    export interface Task {
      id: string;         // Уникальный идентификатор
      title: string;      // Название задачи
      description?: string; // Описание (необязательное поле)
      completed: boolean; // Статус выполнения
      createdAt: Date;    // Дата создания
      priority?: 'low' | 'medium' | 'high'; // Приоритет (необяз., литеральный тип)
    }
    ```
2.  **Подумайте о вспомогательных типах**. Например, тип для создания новой задачи (без `id` и `createdAt`):
    ```typescript
    export type NewTask = Omit<Task, 'id' | 'createdAt'>;
    // NewTask содержит только title, description, completed, priority
    ```

#### **4. Шаг 2: Настройка окружения проекта**
Мы будем использовать **Vite** для сборки и **Vitest** для тестирования — это современный и быстрый стек.
1.  **Создайте новый проект** в пустой папке через терминал:
    ```bash
    npm create vite@latest my-project -- --template vanilla-ts
    cd my-project
    ```
2.  **Установите фреймворк для тестирования** Vitest:
    ```bash
    npm i -D vitest
    ```
3.  **Настройте Vitest**, обновив `vite.config.ts`:
    ```typescript
    import { defineConfig } from 'vite';
    export default defineConfig({
      test: {
        globals: true, // Чтобы не импортировать describe, it, expect в каждый файл
      },
    });
    ```
4.  **Добавьте скрипт для тестов** в `package.json`:
    ```json
    "scripts": {
      "dev": "vite",
      "build": "tsc && vite build",
      "test": "vitest" // <-- Добавьте эту строку
    }
    ```

#### **5. Шаг 3: Организуйте структуру файлов**
Создайте чёткую структуру с самого начала. Ваша папка `src/` может выглядеть так:
```
src/
├── types.ts          # Все основные интерфейсы и типы
├── core/             # Модули с основной логикой (создайте позже)
├── utils/            # Вспомогательные функции (создайте позже)
└── main.ts           # Точка входа (можно временно оставить пустым)
tests/                # Папка для тестов (создайте позже)
index.html
package.json
vite.config.ts
tsconfig.json
```

#### **6. Контрольное задание К12.1**
**Задача:** Заложить архитектурный фундамент вашего финального проекта.
1.  **Определите тему проекта.** Чётко сформулируйте, что будет делать ваше приложение и какую основную сущность обрабатывает (1-2 предложения в файле README.md).
2.  **Создайте и настройте репозиторий.**
    *   Создайте новый публичный репозиторий на вашем хостинге (Github/GitVerse/Codeberg).
    *   Локально выполните шаги 2 и 3 из конспекта выше (создание проекта Vite и установка Vitest).
    *   Создайте базовую структуру папок, как в шаге 4 (или похожую, более подходящую Вам).
    *   Свяжите локальный проект с удалённым репозиторием (`git remote add ...`) и выполните первый коммит и пуш (`git add .`, `git commit -m "project setup"`, `git push`).
3.  **Спроектируйте и опишите ключевые типы данных.**
    *   В файле `src/types.ts` создайте как минимум **3-5 интерфейсов или типов** (`interface`, `type`).
    *   Обязательно опишите главную сущность вашего проекта.
    *   Используйте изученные возможности: необязательные поля (`?`), литеральные типы (например, `'low' | 'medium' | 'high'`), композицию типов.
    * Минимальный набор полей для главной сущности: id, name, status (состояние), createdAt

**Что должно быть результатом:** Ссылка на публичный репозиторий, в котором есть настроенный проект Vite+TypeScript+Vitest и файл `src/types.ts` с описанными типами.

**Совет:** Не пишите пока бизнес-логику! Сфокусируйтесь на структуре и типах. Хорошо продуманные типы сделают дальнейшую разработку намного проще.
