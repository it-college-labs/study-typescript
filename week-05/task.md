# Неделя 05. Классы и ООП

## Задание

Нужно создать систему учета транспортных средств в гараже, используя абстрактные классы, наследование и композицию. Базой должен стать абстрактный класс `Vehicle` со свойствами `brand: string`, `year: number` с модификатором `protected` и `id` с модификаторами `readonly` и `private`; для генерации `id` можно использовать `Date.now()`. В классе должен быть абстрактный метод `getInfo(): string` и публичный метод `startEngine(): void`, выводящий в консоль `Двигатель запущен`.

Создай два наследника `Vehicle`: `Car` и `Motorcycle`. `Car` добавляет модель `model: string`, реализует `getInfo()` строкой `Автомобиль [brand] [model], [year] г.в. (ID: [id])` и переопределяет `startEngine()` так, чтобы перед вызовом `super.startEngine()` выводилась строка `Автомобиль заводится с ключа`. `Motorcycle` добавляет свойство `type: string` и реализует `getInfo()` строкой `Мотоцикл [brand], тип [type], [year] г.в. (ID: [id])`. Так как `id` должен оставаться приватным, для вывода и поиска можно добавить публичный метод чтения идентификатора.

Создай класс `Garage` с приватным массивом `vehicles: Vehicle[]`. В нем должны быть методы `addVehicle(vehicle: Vehicle): void`, `listVehicles(): void` и `findVehicleById(id: number): Vehicle | undefined`. В `main.ts` создай экземпляр гаража, несколько машин и мотоциклов, добавь их в гараж, выведи список через `listVehicles()`, найди транспорт по id и запусти его двигатель.

## Что проверяется

Преподаватель будет смотреть умение работать с абстрактными классами и методами, корректное применение `private`, `protected` и `readonly`, понимание наследования, переопределения методов и вызова `super`, а также моделирование коллекции через композицию в классе `Garage`.
