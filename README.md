# study-typescript

Репозиторий для отработки заданий по курсу TypeScript.

Задания разложены по папкам `week-03` - `week-11`. В каждой папке есть `task.md` с постановкой практического задания и `materials.md` с названием конспекта, примера или исходной ссылки, если ссылка была учебным материалом, а не отдельным заданием.

Неделя `week-10` добавлена по связанной ссылке из задания недели 9: на скрине она отображалась как `README.md`, но внутри gist указано, что это продолжение задания прошлой недели с CLI-командами для todo-приложения.

Папка `final-project` создана для единого финального проекта по неделям 12-14. Эти недели не разделены на отдельные папки, потому что по смыслу это один проект: настройка и типы, ядро, затем CLI или web-интерфейс с ручной проверкой работы.

Файл `sources.md` содержит журнал проверенных ссылок со скринов и поясняет, какие ссылки были включены, а какие оказались чужими результатами или неполной обрезанной строкой.
