# Финальный проект

Здесь будем делать единый проект по неделям 12-14.

## Неделя 12

Выбираем тему проекта, настраиваем TypeScript-проект и описываем основные типы данных в `src/types.ts`. На этом этапе важны тема, структура и типы, а не бизнес-логика.

## Неделя 13

Добавляем ядро проекта: функции или классы для добавления, поиска, изменения, удаления и просмотра данных. В ядре нужно использовать Utility Types, например `Partial`, `Pick`, `Omit`, `Required` или `ReturnType`.

## Неделя 14

Добавляем интерфейс на выбор: CLI или web. Для нашей ситуации удобнее CLI, потому что он быстрее проверяется и требует меньше лишнего кода. Проверка будет текстовой: команды запуска, ожидаемый результат и короткое описание сценариев.

## Рабочая идея

Пока базовый вариант для работы: CLI-приложение для учета расходов. В нем удобно показать типы, хранение данных, операции добавления и изменения, фильтрацию, итоговую сумму и ручную проверку через команды терминала.
