## Тема проекта
Микроприложение для управления CSV-датасетами и оценки их готовности к анализу данных

## Главная сущность
Dataset – в моем случае это описание загружаемого датасета, которое включает в себя название, список колонок, количество строк, статус обработки, дата добавления и путь к  `*.csv` файлу 

## Основные фичи
1. Добавление датасета.
2. Удаление датасета.
3. Редактирование карточки датасета.
4. Просмотр списка датасетов.
5. Фильтрация датасетов по статусу или типу ML-задачи.
6. Хранение описания колонок.
7. Выбор целевой колонки.
8. Просмотр краткой сводки по датасету.

## Цель
**Быстро понять структуру данных**, выбрать целевую колонку, увидеть типы колонок и базовое состояние таблицы для упрощения EDA-процессинга
