# Неделя 11. Utility Types и Type Guard

## Задание

В первой части нужно создать тип `UserEditForm`, используя интерфейс `User` из примеров конспекта. В этом типе все поля должны стать опциональными, кроме поля `id`, которое должно остаться обязательным. Для решения нужно скомбинировать `Partial<T>` с `Required<T>` или `Pick<T, K>`.

Во второй части нужно объявить функцию `processData(input: string): SuccessResponse | ErrorResponse`; полная реализация функции не важна. Затем нужно создать type guard-функцию `isProcessSuccess`, которая принимает неизвестное значение и проверяет, является ли оно успешным результатом выполнения `processData`. Ключевое требование: тип успешного результата в проверке должен быть получен с помощью `ReturnType`, а не указан вручную.

## Что сдать

Нужно предоставить код с интерфейсами `SuccessResponse` и `ErrorResponse`, объявлением `processData`, типом `UserEditForm` и функцией `isProcessSuccess`. Полную реализацию бизнес-логики и вызывающий код присылать не нужно; достаточно деклараций, демонстрирующих работу с Utility Types.
