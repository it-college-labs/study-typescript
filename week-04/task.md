# Неделя 04. Дженерики, перегрузка функций и Utility Types

## Задание

Нужно применить дженерики, перегрузку функций и утилитные типы на практике. Создай универсальную функцию `toArray<T>(...args: T[]): T[]`, которая принимает произвольное число аргументов одного типа и возвращает массив из этих аргументов.

Объяви перегруженную функцию `parseInput(input: string): number` и `parseInput(input: string, radix: number): number`. Реализация должна использовать `parseInt`, а в коде нужно показать вызов функции в двух вариантах.

Дан интерфейс `Book` с полями `isbn: string`, `title: string`, `author: string`, `pages: number` и `inStockCount: number`. На его основе создай тип `BookCatalogItem` без поля `inStockCount`, а затем тип `LibraryCatalog`, где ключом является строковый `isbn`, а значением объект типа `BookCatalogItem`.

## Что сдать

Нужен TypeScript-файл с объявлениями функций, интерфейса и типов. Код должен компилироваться без ошибок при проверке командой `tsc --noEmit`.
