# Неделя 07. Асинхронность в TypeScript

## Задание

Нужно написать типизированную асинхронную функцию для работы с API. В качестве основы используй функцию `fetchUser` из конспекта, доработай ее так, чтобы при успешном запросе она дополнительно выводила в консоль город пользователя через `user.address.city`, и обязательно добавь тип для `address.city` в интерфейс `User`.

Для дополнительной практики можно сделать продвинутую часть: написать функцию `fetchUsers(city?: string): Promise<User[]>`, которая загружает всех пользователей с `https://jsonplaceholder.typicode.com/users` и, если передан город, возвращает только пользователей из этого города.

## Требования

Все функции должны иметь явные типы аргументов и возвращаемых значений. В решении обязательно использовать `async/await`, обработать ошибки через `try/catch` и добиться компиляции без ошибок TypeScript при включенных строгих настройках.

## Что сдать

Нужно предоставить файл `api.ts` с функциями и интерфейсами. Преподавателю отправляется ссылка на репозиторий с выполненным заданием.
