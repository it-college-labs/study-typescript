# Неделя 08. React и TypeScript

## Задание

Нужно создать полностью типизированный React-компонент `Timer`, принимающий проп `initialSeconds: number` и отсчитывающий время вниз до нуля. В компоненте должен быть интерфейс `TimerProps`, состояние оставшегося времени через `useState<number>` и корректная очистка таймера внутри `useEffect`.

В варианте с `setInterval` эффект создает интервал, который каждую секунду уменьшает значение `seconds` на 1. При размонтировании компонента или изменении зависимостей интервал нужно очищать через `clearInterval`. Когда `seconds` становится равным или меньше нуля, интервал останавливается, а компонент показывает сообщение `Time's up!`; пока время идет, компонент отображает строку `Осталось: X сек.`.

В варианте с `setTimeout` эффект запускает одиночный таймер на один тик и зависит от `seconds`. Если `seconds <= 0`, эффект больше не ставит таймер и компонент выводит `Время вышло`. Если время еще есть, `setTimeout` через 1000 мс уменьшает `seconds` на 1, а функция очистки вызывает `clearTimeout` для текущего таймера. Для хранения идентификатора таймера можно использовать `useRef`.

## Что сдать

Нужен типизированный компонент `Timer`, который корректно работает, очищает таймеры и останавливается при завершении отсчета. Можно выполнить один из вариантов, но вариант с `setTimeout` глубже проверяет понимание зависимостей `useEffect`.
